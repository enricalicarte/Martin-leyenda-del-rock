# Martín, leyenda del rock 🎸

Juego musical de ritmo para el navegador, en un solo archivo HTML.
Sasha a la guitarra y el abuelo Martín al saxo hacen una gira mundial por
diez escenarios, de los años 50 hasta hoy.

## Estructura

- `index.html`: el juego.
- `audio/`: la música de cada canción (fondo y guitarra por separado). Protegida, ver Derechos.

## Jugar

Publica la carpeta con GitHub Pages
(Settings → Pages → rama `main`, carpeta raíz).
Abrir `index.html` directamente desde el disco no carga la música: hace
falta un servidor, como GitHub Pages.

- Móvil: toca los cinco botones de colores.
- Ordenador: teclas A S D F G y la barra espaciadora para el superpoder.
- Las canciones vacías aceptan un MP3: el juego crea las notas solo y las
  guarda en ese dispositivo.
